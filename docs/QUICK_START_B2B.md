# 🚀 دليل سريع: إنشاء عميل B2B وإصدار فاتورة

## ⚡ في 5 دقائق فقط!

---

## 📝 الجزء الأول: إنشاء عميل B2B

### الخطوة 1️⃣: افتح صفحة العملاء
```
القائمة الجانبية → Customers → Add Customer
```

### الخطوة 2️⃣: املأ البيانات الأساسية
```
✏️ Customer Name: شركة الأمثلة المحدودة
📱 Phone: 0501234567
📧 Email: info@example.com
```

### الخطوة 3️⃣: اختر B2B
```
📋 Invoice Type: اختر "B2B - Tax Invoice"
```
**⚠️ مهم**: بمجرد اختيار B2B، ستظهر حقول إضافية!

### الخطوة 4️⃣: املأ بيانات B2B
```
🔢 VAT Number: 300123456789003 (15 رقم)
🏢 Building Number: 1234
🛣️ Street Name: شارع الملك فهد
🏘️ District: العليا
🌆 City: الرياض
📮 Postal Code: 12345
🌍 Country Code: SA
```

### الخطوة 5️⃣: احفظ
```
اضغط زر "Save" ✅
```

---

## 🧾 الجزء الثاني: إصدار فاتورة B2B

### الخطوة 1️⃣: افتح صفحة المبيعات
```
القائمة الجانبية → Sales → Add Sale
```

### الخطوة 2️⃣: اختر العميل
```
👤 Customer: اختر "شركة الأمثلة المحدودة"
```
**✨ تلقائياً**: سيتم تحديد نوع الفاتورة كـ B2B

### الخطوة 3️⃣: أضف المنتجات
```
📦 Product 1: لابتوب × 2 = 4,000 ريال
📦 Product 2: ماوس × 5 = 250 ريال
```

### الخطوة 4️⃣: الضريبة
```
💰 Subtotal: 4,250 ريال
📊 VAT (15%): 637.50 ريال
💵 Total: 4,887.50 ريال
```

### الخطوة 5️⃣: احفظ واطبع
```
اضغط "Save" ثم "Print" 🖨️
```

---

## 📋 Checklist سريع

### قبل إنشاء العميل:
- [ ] هل لديك الرقم الضريبي للعميل؟ (15 رقم)
- [ ] هل لديك العنوان الكامل؟
- [ ] هل العميل شركة أو مؤسسة؟

### عند إنشاء العميل:
- [ ] اخترت "B2B - Tax Invoice"
- [ ] أدخلت الرقم الضريبي (15 رقم)
- [ ] ملأت جميع حقول العنوان
- [ ] حفظت العميل بنجاح

### عند إصدار الفاتورة:
- [ ] اخترت العميل B2B الصحيح
- [ ] أضفت المنتجات
- [ ] تحققت من الضريبة (15%)
- [ ] حفظت الفاتورة

## 🎯 مثال سريع

### بيانات العميل:

| البند | القيمة |

| **الإجمالي** | **4,887.50 ريال** |

## ⚠️ أخطاء شائعة

### ❌ خطأ 1: الرقم الضريبي قصير
```
خطأ: 12345678
صحيح: 300123456789003 (15 رقم)
```

### ❌ خطأ 2: نسيت ملء العنوان
```
جميع حقول العنوان إلزامية للـ B2B:
✅ Building Number
✅ Street Name
✅ District
✅ City
✅ Postal Code
```

### ❌ خطأ 3: اخترت B2C بدلاً من B2B
```
تأكد من اختيار: "B2B - Tax Invoice"
وليس: "B2C - Simplified Invoice"
```

## 💡 نصائح مهمة

### 1. احفظ قالب للعملاء B2B
إذا كان لديك عملاء B2B كثيرون، احفظ قالب بالحقول المطلوبة.

### 2. تحقق من الرقم الضريبي
يمكنك التحقق من صحة الرقم الضريبي على موقع الهيئة:
https://zatca.gov.sa

### 3. استخدم Copy/Paste
انسخ العنوان من سجل تجاري العميل مباشرة.

### 4. راجع الفاتورة قبل الإرسال
تأكد من صحة جميع البيانات قبل إرسال الفاتورة لـ ZATCA.
