# الفرق بين فاتورة B2C و B2B

## 📋 نظرة عامة

النظام الآن يدعم نوعين من الفواتير، وكل نوع له شكل وتفاصيل مختلفة.

---

## 🔵 فاتورة B2C (Simplified Tax Invoice)

### متى تُستخدم؟
- للعملاء الأفراد (المستهلك النهائي)
- للعملاء بدون رقم ضريبي
- للمعاملات البسيطة

### المعلومات المعروضة:

#### معلومات العميل:
- ✅ الاسم
- ✅ رقم الهاتف
- ✅ العنوان (بسيط)

#### معلومات الشركة:
- ✅ اسم الشركة
- ✅ الشعار
- ✅ العنوان (بسيط)
- ✅ رقم الهاتف
- ✅ البريد الإلكتروني
- ✅ الرقم الضريبي للشركة

#### العنوان:
```
Simplified Tax Invoice / فاتورة ضريبية مبسطة
```

---

## 🟢 فاتورة B2B (Tax Invoice)

### متى تُستخدم؟
- للشركات والمؤسسات
- للعملاء الذين لديهم رقم ضريبي
- للمعاملات التجارية

### المعلومات المعروضة:

#### معلومات العميل:
- ✅ الاسم
- ✅ **الرقم الضريبي** (15 رقم)
- ✅ رقم الهاتف
- ✅ **رقم المبنى**
- ✅ **اسم الشارع**
- ✅ **الحي**
- ✅ **المدينة**
- ✅ **الرمز البريدي**
- ✅ **كود الدولة**

#### معلومات الشركة:
- ✅ اسم الشركة
- ✅ الشعار
- ✅ **رقم المبنى**
- ✅ **اسم الشارع**
- ✅ **الحي**
- ✅ **المدينة**
- ✅ **الرمز البريدي**
- ✅ رقم الهاتف
- ✅ البريد الإلكتروني
- ✅ الرقم الضريبي للشركة

#### العنوان:
```
Tax Invoice / فاتورة ضريبية
```

## 🔄 كيف يتم تحديد نوع الفاتورة؟

### تلقائياً:
عند إنشاء فاتورة جديدة، النظام يحدد النوع تلقائياً من نوع العميل:

```php
// في Sale Controller
$party = Party::find($request->party_id);
$invoice_type = $party && $party->zatca_type === 'b2b' ? 'b2b' : 'b2c';
```

### النتيجة:
- إذا كان العميل **B2B** → الفاتورة ستكون **B2B**
- إذا كان العميل **B2C** → الفاتورة ستكون **B2C**
- إذا كان **Guest** → الفاتورة ستكون **B2C**

## 🎯 متطلبات ZATCA

### B2C (Simplified):
- ✅ يتم **إبلاغ** ZATCA (Report)
- ✅ لا تحتاج موافقة مسبقة
- ✅ يمكن إعطاء الفاتورة للعميل فوراً

### B2B (Tax Invoice):
- ✅ يتم **مقاصة** مع ZATCA (Clear)
- ⚠️ تحتاج موافقة مسبقة من ZATCA
- ⚠️ لا يمكن إعطاء الفاتورة للعميل إلا بعد الموافقة

## ✅ Checklist

عند إصدار فاتورة، تأكد من:

### للـ B2C:
- [ ] العميل من نوع B2C أو Guest
- [ ] الفاتورة تظهر "Simplified Tax Invoice"
- [ ] المعلومات بسيطة (اسم، هاتف، عنوان)

### للـ B2B:
- [ ] العميل من نوع B2B
- [ ] العميل لديه رقم ضريبي (15 رقم)
- [ ] العميل لديه عنوان كامل
- [ ] الفاتورة تظهر "Tax Invoice"
- [ ] جميع التفاصيل معروضة (رقم ضريبي، عنوان كامل)

## 📞 الدعم

إذا كانت الفاتورة لا تظهر بالشكل الصحيح:

1. تحقق من نوع العميل في قاعدة البيانات:
   ```sql
   SELECT id, name, zatca_type FROM parties WHERE id = X;
   ```

2. تحقق من نوع الفاتورة:
   ```sql
   SELECT id, invoiceNumber, invoice_type FROM sales WHERE id = X;
   ```

3. امسح الـ cache:
   ```bash
   php artisan view:clear
   ```

4. أعد تحميل الصفحة بـ Ctrl+Shift+R
