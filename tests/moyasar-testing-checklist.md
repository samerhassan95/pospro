# قائمة فحص تكامل ميسر - Moyasar Integration Testing Checklist

## 1. إعداد بيئة الاختبار

### أ) الحصول على مفاتيح الاختبار من ميسر
```bash
# Test API Keys من لوحة تحكم ميسر
MOYASAR_TEST_PUBLISHABLE_KEY=pk_test_xxxxxxxxxx
MOYASAR_TEST_SECRET_KEY=sk_test_xxxxxxxxxx
```

### ب) تحديث ملف البيئة
```env
# في ملف .env
MOYASAR_ENVIRONMENT=test
MOYASAR_PUBLISHABLE_KEY=pk_test_xxxxxxxxxx
MOYASAR_SECRET_KEY=sk_test_xxxxxxxxxx
```

## 2. اختبار الوظائف الأساسية

### أ) اختبار إعدادات ميسر
- [ ] الدخول إلى إعدادات ميسر في لوحة التحكم
- [ ] حفظ مفاتيح API للاختبار
- [ ] التأكد من حفظ الإعدادات بنجاح

### ب) اختبار دفع المبيعات
- [ ] إنشاء فاتورة مبيعات جديدة
- [ ] النقر على "دفع بميسر"
- [ ] اختبار بطاقة ائتمان تجريبية: `4111111111111111`
- [ ] التأكد من نجاح الدفع وتحديث حالة الفاتورة

### ج) اختبار دفع المشتريات
- [ ] إنشاء فاتورة مشتريات
- [ ] اختبار دفع المستحقات
- [ ] التحقق من تحديث الرصيد

### د) اختبار تحصيل المستحقات
- [ ] الذهاب إلى صفحة المستحقات
- [ ] اختبار دفع مستحق عميل
- [ ] التأكد من تحديث رصيد العميل

## 3. اختبار بطاقات الاختبار

### بطاقات ائتمان تجريبية
```
# بطاقة نجح الدفع
4111111111111111 - CVV: 123 - تاريخ انتهاء: أي تاريخ مستقبلي

# بطاقة فشل الدفع
4000000000000002 - CVV: 123 - تاريخ انتهاء: أي تاريخ مستقبلي

# بطاقة مدى تجريبية
5297410000000000 - CVV: 123 - تاريخ انتهاء: أي تاريخ مستقبلي
```

## 4. اختبار السيناريوهات المختلفة

### أ) اختبار الأخطاء
- [ ] اختبار بطاقة منتهية الصلاحية
- [ ] اختبار CVV خاطئ
- [ ] اختبار رصيد غير كافي
- [ ] اختبار انقطاع الإنترنت

### ب) اختبار واجهة المستخدم
- [ ] اختبار على الهاتف المحمول
- [ ] اختبار على التابلت
- [ ] اختبار على سطح المكتب
- [ ] اختبار باللغة العربية والإنجليزية

## 5. فحص قاعدة البيانات

### التحقق من حفظ البيانات
```sql
-- فحص جدول المدفوعات
SELECT * FROM payments WHERE gateway = 'moyasar' ORDER BY created_at DESC LIMIT 10;

-- فحص جدول المبيعات
SELECT * FROM sales WHERE payment_status = 'paid' ORDER BY created_at DESC LIMIT 5;

-- فحص إعدادات ميسر
SELECT moyasar_setting FROM businesses WHERE id = YOUR_BUSINESS_ID;
```

## 6. اختبار الأمان

### فحص الأمان
- [ ] التأكد من تشفير مفاتيح API في قاعدة البيانات
- [ ] فحص استخدام HTTPS في جميع طلبات الدفع
- [ ] التحقق من عدم ظهور المفاتيح السرية في الكود المصدري
- [ ] اختبار انتهاء صلاحية الجلسة

## 7. اختبار الأداء

### قياس الأداء
- [ ] قياس وقت تحميل صفحة الدفع
- [ ] اختبار الدفع مع اتصال إنترنت بطيء
- [ ] اختبار عدة عمليات دفع متزامنة
- [ ] فحص استهلاك الذاكرة

## 8. اختبار التقارير والسجلات

### فحص السجلات
- [ ] فحص سجلات Laravel في `storage/logs/laravel.log`
- [ ] التحقق من سجلات ميسر في لوحة التحكم
- [ ] فحص تقارير المدفوعات في النظام
- [ ] التأكد من دقة الأرقام والمبالغ

## 9. الانتقال إلى بيئة الإنتاج

### قبل النشر
- [ ] الحصول على مفاتيح الإنتاج من ميسر
- [ ] تحديث متغيرات البيئة للإنتاج
- [ ] اختبار نهائي في بيئة مشابهة للإنتاج
- [ ] إنشاء نسخة احتياطية من قاعدة البيانات

### بعد النشر
- [ ] اختبار عملية دفع حقيقية بمبلغ صغير
- [ ] مراقبة السجلات لأول 24 ساعة
- [ ] التأكد من وصول إشعارات الدفع
- [ ] فحص التقارير المالية

## 10. أوامر مفيدة للاختبار

### أوامر Laravel
```bash
# مسح الكاش
php artisan cache:clear
php artisan config:clear

# فحص الاتصال بقاعدة البيانات
php artisan tinker
>>> DB::connection()->getPdo();

# تشغيل الاختبارات
php artisan test --filter=MoyasarTest

# مراقبة السجلات
tail -f storage/logs/laravel.log
```

### اختبار API مباشرة
```bash
# اختبار إنشاء دفعة
curl -X POST https://api.moyasar.com/v1/payments \
  -H "Authorization: Basic $(echo -n 'sk_test_xxxxx:' | base64)" \
  -d "amount=1000" \
  -d "currency=SAR" \
  -d "description=Test Payment"
```
